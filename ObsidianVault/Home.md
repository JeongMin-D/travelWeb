# ✈️ 안티그래비티 트래블 - 옵시디언 볼트 (Obsidian Vault)

**안티그래비티 트래블 (Antigravity Travel)** 프로젝트 지식 베이스에 오신 것을 환영합니다! 이 볼트는 프로젝트의 전체 생명 주기, 아키텍처 의사결정, 수정 사항, 버그 로그 및 향후 개발 로드맵을 유기적으로 연결하여 관리할 수 있는 마크다운 위키입니다.

이 폴더(`ObsidianVault/`)를 **옵시디언(Obsidian)** 앱에서 직접 볼트로 열어 인터랙티브 그래프 뷰를 탐색하고 문서 간의 연결 관계를 한눈에 확인해 보세요.

---

## 🛠️ 프로젝트 스냅샷
* **현재 버전**: `v1.2.0 (1996 레트로 에디션)`
* **기술 스택**: React 18, Vite 6, Leaflet 1.9, 바닐라 CSS (Vanilla CSS)
* **디자인 철학**: 데스크톱 화면 비율에 유연하게 맞추는 96% 비율형 카탈로그 잡지 레이아웃 (`max-width: 1500px`), 고정밀 구글 지도 연동, 둥근 모서리 없는 완전 직각 테두리 및 1996년 감성의 레트로 스티커 테마.
