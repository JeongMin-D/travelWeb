# 🚀 향후 개발 로드맵 (Future Roadmap)

이 문서는 **VOYAGE Travel Planner**의 장기 제품 백로그입니다. 현재 실행 순서와 완료 기준은 [[03-Planning/Active Plan|실행 계획]]에서 관리합니다.

---

## 🔮 차기 기능 개발 백로그 (Backlog)

### 1. 항공권 예약 연동 및 좌석 조회 시뮬레이션
* **개념**: 1996년도 항공 편명 및 잔여 좌석 조회 시스템 에뮬레이션 (예: "DELL AIRWAYS").
* **세부 기능**:
  - 출국일, 목적지, 이코노미/비즈니스 등의 클래스를 인풋 창으로 입력받아 가상 스케줄 리스트를 표출.
  - 예약 클릭 시 발생 비용을 가계부 **예산 트래커(Budget Tracker)** 지출 항목에 즉시 기입 연동.

### 2. 기후/날씨 API 연동 및 의류 가이드 자동 인젝션
* **개념**: 실시간 날씨 데이터 및 사계절 기후 통계를 연계한 짐 싸기 가이드.
* **세부 기능**:
  - 선택한 여행지의 당일 기상 정보(혹은 월평균 기온)를 수집하여 Itinerary 준비물 체크리스트에 옷차림 조언 추가.
  - 비가 오면 `☂️ 우산/우비`, 한파 시 `🧣 패딩/목도리`, 자외선 지수 높을 시 `🕶️ 선글라스` 등의 준비물을 체크리스트에 실시간 강제 삽입하여 유연성 확보.

### 3. 카탈로그 브로셔 스타일 프린트 / PDF 내보내기
* **개념**: 작성한 일정표와 경비 보고서를 1996년 인쇄용 종이 브로셔 포맷으로 PDF 출력 지원.
* **세부 기능**:
  - CSS 미디어 쿼리(`@media print`)를 코딩하여, 출력 시 사이드바 및 네비게이션을 숨김 처리.
  - 종이 규격에 완벽히 정렬되는 깔끔한 격자형 흑백 카탈로그 리본 카드 디자인으로 자동 출력 정렬.

### 4. 카테고리별 예산 시각화 차트 및 타겟 제한 경고
* **개념**: 예산 트래커 고도화 분석.
* **세부 기능**:
  - 식비, 교통비, 숙박비, 쇼핑비 등의 지출 카테고리를 분류.
  - 가로 막대바 외에 원형(Pie) 차트나 도넛 차트로 항목별 비중을 표시하고, 한도 예산에 근접(80% 초과)할 경우 1996 스타일의 빨간색 "WARNING! BUDGET EXCEEDED" 경고 스티커 점멸.
