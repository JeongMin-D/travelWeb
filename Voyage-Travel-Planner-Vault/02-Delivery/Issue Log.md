# 🐛 버그 리포트 & 해결 방안 (Bug Reports & Fixes)

이 문서는 개발 및 운영 과정에서 발생한 핵심 시스템 버그와 이를 조치한 해결 가이드라인을 상세 기술한 리포트입니다.

---

## 🐞 Bug 1: Vite 빌드 파서 문자열 종결 안 됨 에러
* **현상**: `[plugin:vite:oxc] Transform failed with 1 error: [PARSE_ERROR] Unterminated string ... src/data/destinations.js:401`
* **원인**: 데이터베이스 지오코딩 및 도시 정보 자동 확장 루프에서, 싱가포르 및 다른 도시들의 일정 설명 필드에 이모지 또는 백슬래시, 따옴표가 잘못 엉켜 문자열이 종결되지 않아 Vite 트랜스파일러가 구문 분석에 실패했습니다.
* **해결**: 데이터 세트 내의 엉킨 문자 코드를 정리하고, 문자열 속의 이중 따옴표를 정규화하여 닫는 문자열 `"` 부호를 온전히 수정하여 빌드 정상 구동을 복구했습니다.

## 🐞 Bug 2: 4일차 및 5일차 일정 데이터 공백 발생
* **현상**: 여행 기간을 5일로 선택했음에도, 데이터베이스 내부 일정 일수가 3일만 존재하는 일부 중소도시의 경우 4일차와 5일차 일정이 통째로 비어 있는 오류가 있었습니다.
* **원인**: 일정 렌더러가 데이터베이스에 존재하지 않는 인덱스에 대해 예외 처리를 수행하지 않아 빈 상태로 렌더링을 시도했기 때문입니다.
* **해결**: **5일 자동 일정 확장 엔진(5-Day Auto-Extension Engine)**을 구축하여:
  - 4일차에는 `NEIGHBOR_MAPPING` 데이터셋을 활용해 인접 근교 도시 투어(예: 오사카 ➔ 나라/교토 당일치기) 일정을 주입했습니다.
  - 근교 도시가 매핑되지 않은 곳의 경우 지역 랜드마크 자유 탐방을 동적으로 인젝션했습니다.
  - 5일차에는 출국 일정에 맞춰 기념품 쇼핑 및 공항 복귀 일정을 생성하여 공백 없이 타임라인이 안전하게 닫히도록 마감했습니다.

## 🐞 Bug 3: Geocoder Nominatim API 403 Forbidden 오류
* **현상**: 파이썬 스크립트(`geocode_all.py`)로 500개 이상의 도시를 자동 검색하여 위경도를 수집할 때 `403 Forbidden` 네트워크 에러가 발생하며 수집이 중단되었습니다.
* **원인**: OpenStreetMap의 Nominatim 서비스는 크롤링 및 악성 요청 방지를 위해 일반 urllib/python 기본 유저에이전트 헤더를 차단하며, 요청 사이에 딜레이가 없을 경우 IP를 영구 밴합니다.
* **해결**:
  - 파이썬 요청 헤더에 크롬 브라우저 정보(`Mozilla/5.0 ...`)를 변조 주입했습니다.
  - API 정책 규정에 부합하도록 요청 당 `time.sleep(0.8)`의 지연시간을 부여했습니다.
  - 실행 중 크래시가 나더라도 진행 상태를 보존하고 건너뛸 수 있도록 캐시 저장 기능(`geocodes_cache.json`)을 빌드하여 안전하게 좌표계 수집을 최종 완수했습니다.

## 🐞 Bug 4: 구글 지도 레이블 다국어 혼재 노출
* **현상**: 구글 지도를 로드할 때 일부 레이블이 영어, 일어, 혹은 브라우저의 디폴트 해외 헤더에 따라 다국어로 깨져 표시되었습니다.
* **원인**: 구글 맵 타일 API 주소(`lyrs=m`)를 매핑할 때, 특정 브라우저 지리 위치 기반 언어로 자동 송출되어 국문 표시가 보장되지 않았습니다.
* **해결**: Leaflet 지도의 모든 렌더 파트 타일 API 주소 뒤에 국문 로케일 옵션인 **`&hl=ko`** 파라미터를 강제 주입하여, 전 세계 어느 지점을 비추더라도 모든 도로명과 명칭이 한글로 번역되어 나오도록 해결했습니다.

## 🐞 Bug 5: 고해상도 대화면 모니터에서의 레이아웃 가로 늘어짐 및 여백 현상
* **현상**: 모던 1080p 및 1440p 디스플레이에서 1996 카탈로그 뷰가 가로로 비정상적으로 길게 뻗어버려 요소들이 작고 비어 있는 영역이 과도했습니다. 또한 노트북 등 다양한 디바이스 비율에서 좌우 빈 영역이 발생했습니다.
* **원인**: `.app-container`와 메인 그리드들이 정적인 가로폭 한계선 없이 백분율로만 늘어났거나 픽셀이 제어되어 화면 종횡비를 따라가지 못했기 때문입니다.
* **해결**:
  - 가로 크기를 디바이스 너비에 맞게 **100% 전체 화면 비율**로 맞춰 확장시킴으로써 좌우 빈 공간을 완전히 제거했습니다.
  - 가이드 브로셔 클론 과정에서 유입된 실재하지 않는 특가 판매 상품 카드 영역 및 텍스트 템플릿을 완전히 제거하여 지면을 정비했습니다.
  - 썸네일 노치 이미지와 폰트, 간격 등을 전면 증대시켰습니다.

## 🐞 Bug 6: 탭(페이지) 전환 시 가로폭 크기가 멋대로 줄어드는 버그
* **현상**: 여행지 검색, 세계 지도, 다녀온 도시 등의 상단 탭을 전환할 때마다 브라우저가 화면 가로 길이를 강제로 늘이거나 좁혀 레이아웃이 덜덜 떨리는 듯한 흔들림 현상이 발생했습니다.
* **원인**: `body`에 설정된 `display: flex; justify-content: center;` 정렬과 컨테이너의 백분율 넓이(`width: 100%`)가 결합되어, 내용물이 적은 탭을 띄우면 브라우저가 콘텐츠 길이에 맞춰 화면 폭을 줄이는 계산(Shrink-to-fit)을 진행했기 때문입니다.
* **해결**:
  - `body`에 할당된 flex 정렬을 제거하고, 마진 오토 방식을 배제하여 브라우저 가로를 가득 채우게 구성했습니다.
  - `.app-container`를 `width: 100%` 구조로 통일하여 어떤 페이지로 넘어가더라도 가로폭이 항상 기기 스크린 너비에 맞춰 100% 고정되게 복구했습니다.

## 🐞 Bug 7: 특정 도시 및 디렉토리 국가 사진 매칭/누락 오류
* **현상**: 여행지 카드 및 대시보드에서 몇몇 대표 도시의 카드 썸네일 이미지가 실제 도시와 맞지 않거나, 특정 브라우저 환경에서 사진 자체가 아예 보이지 않고 비어 있는 엑스박스(404) 누락 현상이 발생했습니다. (제주, 부산, 경주, 강릉, 여수 등에서 사진이 나오지 않는 오작동 확인)
* **원인**: `destinations.js`에 설정된 Unsplash 이미지 소스 중 일부 오래된 이미지 ID가 Unsplash 플랫폼에서 만료/삭제되었거나, 특정 이미지에 적용된 도메인/보안 정책 문제로 인해 클라이언트 브라우저에서 차단(404)되었기 때문입니다. 또한, 기존에 등록되어 있는 도시의 방문 리스트(`localStorage`)가 갱신 전의 예전 이미지 URL 캐시를 물고 있어서 DB 수정 이후에도 대체 텍스트가 남아 있었습니다.
* **해결**:
  - 프리미엄 도시들의 이미지 주소들을 **지리 설명과 정확히 일치하면서 100% 정상 작동하는 Unsplash 공식 고화질 이미지**로 최종 매칭 및 등록 완료했습니다.
    - **부산 / 여수**: 광안대교 및 여수 밤바다의 낭만을 온전히 표현하고, 404 차단 우회를 보장하는 **밤바다 위를 가로지르는 웅장한 대현수교(suspension bridge) 검증 이미지** (`photo-1506012787146-f92b2d7d6d96`)로 단일 매칭 및 최종 등록 완료했습니다.
    - **제주 / 강릉**: 청량하고 아름다운 남해/동해/태평양 바다 해안선 및 백사장 이미지 (`photo-1507525428034-b723cf961d3e`)로 개편 완료.
    - **경주 / 전주 / 국내 기본값**: 동양의 고풍스러운 역사와 고궁의 기와지붕을 정교하게 묘사하는 실제 **전통 목조 오중탑(pagoda/temple) 검증 이미지** (`photo-1493976040374-85c8e12f0c0e`)로 완벽 복구 완료.
    - **바르셀로나**: Biel Morro 작가의 사그라다 파밀리아 대성당 주간 정경 검증 이미지 (`photo-1511527661048-7fe73d85e9a4`)로 복구 완료.
  - `VisitedTracker.jsx` 컴포넌트의 최초 마운트 `useEffect` 단에 **로컬 스토리지 자동 이미지 동기화(Sync) 로직**을 탑재하여, 기존 방문 목록에 잘못 남아 있던 옛날 이미지 캐시들까지 한 번에 최신 이미지 경로로 안전하게 청소 및 교체되도록 자동화 패치했습니다.
