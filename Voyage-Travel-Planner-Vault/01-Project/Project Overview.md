# 프로젝트 개요

## 제품 목표

VOYAGE는 여행지를 찾고, 랜덤 추천을 받고, 맞춤 일정을 검토한 뒤 예산과 방문 기록까지 이어서 관리하는 웹 앱입니다.

## 현재 기능

- 대륙·국가·도시 검색과 여행지 카드 탐색
- 지도 위 다트 방식의 랜덤 여행지 추천
- 1~14일 일정, 준비물, 주변 여행지 제안
- 여행 경로 지도와 인쇄용 브로셔
- 예산 추적과 방문 도시 기록
- 한국어/영어, 라이트/다크 테마 전환

## 범위 원칙

- 여행 탐색과 계획에 직접 도움이 되는 기능을 우선합니다.
- 실제 예약·결제처럼 외부 계약이나 민감한 데이터가 필요한 기능은 별도 검토 후 도입합니다.
- 도시 데이터는 지도 위치, 영문 표기, 국가/대륙 분류가 함께 완성되어야 합니다.
